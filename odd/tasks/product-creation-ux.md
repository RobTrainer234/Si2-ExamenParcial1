# Product creation UX

## Goal
Make CU05 product registration faster and more intuitive for administrators while preserving backend payloads and existing variant, image, and stock workflows.

## Tasks
- [x] Simplify the product creation form into an essential-data first screen with progressive disclosure cues.
- [x] Add clear success feedback and next-step actions for variants, images, and stock after creation.
- [x] Improve labels, helper text, local validation errors, responsive layout, and accessible action semantics.
- [x] Verify Angular web tests and build.
- [x] Generate editable product code and slug suggestions from the product name.
- [x] Verify generated values and container deployment.
- [x] Simplify size creation to one visible size field with automatic type and sort-order detection.
